
# SecureSpace — Login Authentication UI

A responsive login and registration interface built using HTML, CSS, and JavaScript as part of the Oasis Infobyte Web Development & Designing Internship.

## Features
- Login and registration forms
- Switch between login and registration
- Name, email, and password input validation
- Password confirmation validation
- Clear validation and feedback messages
- Demonstration dashboard
- Sign-out button
- Responsive layout for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Important Security Note
This is a front-end demonstration project only. It does not verify real user accounts or provide secure authentication. Registration does not store passwords. A production application requires a secure backend, password hashing, and appropriate session management.

## Learning Outcomes
- Creating login and registration interfaces
- Validating form inputs with JavaScript
- Handling form events and displaying feedback
- Building responsive user interfaces
- Understanding the difference between a front-end demo and secure authentication
