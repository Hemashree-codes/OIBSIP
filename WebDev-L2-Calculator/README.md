
# Calcify — Smart Calculator

## About the Project
Calcify is a responsive browser-based calculator built using HTML5, CSS3, and vanilla JavaScript. It provides a simple interface for performing basic arithmetic operations.

## Features
- Addition, subtraction, multiplication, and division
- Numeric buttons from 0 to 9
- Decimal point and positive/negative sign controls
- Clear (AC) and backspace buttons
- Error handling for division by zero
- Keyboard support for numbers and arithmetic operators
- Responsive layout for desktop and mobile screens
- Modern dark theme with a gradient background

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the live demo in a web browser.
2. Enter numbers using the on-screen buttons or keyboard.
3. Select an arithmetic operator.
4. Enter the next number and press equals.
5. Use AC to reset or backspace to remove the last digit.
