
# TempFlow — Temperature Converter

## Oasis Infobyte Internship

- **Track:** Web Development & Designing
- **Level:** Level 1
- **Task:** Task 3 — Temperature Converter

## About the Project

TempFlow is a responsive temperature conversion website that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert between Celsius, Fahrenheit, and Kelvin
- Validate temperature input
- Reject values below absolute zero
- Reset the converter
- Responsive dark-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser, or run it using VS Code Live Server.
3. Enter a temperature and choose the source and destination units.
4. Click **Convert Temperature**.

## Project Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — conversion calculations
