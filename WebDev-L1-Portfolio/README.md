
# Personal Portfolio Website

## Oasis Infobyte Internship
- **Track:** Web Development & Designing
- **Level:** Level 1
- **Task:** Task 2 — Personal Portfolio

## About the Project
This project is a modern, dark-themed personal portfolio website.
It presents my introduction, technical skills, projects, education,
and professional links in a responsive layout.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Features
- Sticky navigation bar
- Hero section with introduction
- About Me section
- Technical Skills cards
- Project showcase
- Education section
- GitHub and LinkedIn links
- Responsive layout for mobile and desktop
- Dark theme with purple accents

## Project Structure
```text
WebDev-L1-Portfolio/
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
