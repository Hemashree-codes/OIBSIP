
# Dr. A. P. J. Abdul Kalam — Tribute Page

## About the Project
A responsive tribute website dedicated to Dr. A. P. J. Abdul Kalam, India's former President and renowned scientist. The page highlights his life, scientific contributions, achievements, and legacy.

## Features
- Responsive hero section and navigation bar
- Biography with original written content
- Timeline of major milestones
- Inspirational quote section
- Consistent navy-blue, cream, and gold colour palette
- Smooth-scroll navigation
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- Google Fonts
