
# WebStart - Landing Page

## About the Project
WebStart is a responsive landing page introducing beginners to web development.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Features
- Sticky navigation bar
- Hero section with a call-to-action button
- HTML, CSS, and JavaScript learning cards
- About section
- Contact and social links
- Responsive mobile layout

## How to Run
Open `index.html` in a web browser.
